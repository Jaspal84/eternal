# INDIAN RHYTHMS PRO v1.0.0

Original synthesized Bollywood & Punjabi percussion: 246 mono one-shots with three velocity layers and two round robins; 1,008 MIDI grooves; 1,008 stereo PCM24/48 kHz WAV loops; nine SFZ maps; reproducible Python sources, tests, and Logic instructions. Original material is supplied under the included permissive license for royalty-free musical use.

Download all three ZIP parts and both checksum files. Follow RECONSTRUCT_MACOS.md to verify and reconstruct the complete ZIP before extracting. GitHub's automatic source archives do not contain the audio library.

Original Linux build: six unit tests and 69,467 validation checks passed. ZIP integrity was verified. These are synthetic approximations, not acoustic recordings. Listening review, macOS/Logic/SFZ playback and Sonic Atlas custom import remain unverified. RMS targets do not guarantee equal perceived loudness.

This release distributes the original validated library ZIP unchanged. Release preparation and CI configuration added later are available in the tagged repository source.
