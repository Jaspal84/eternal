# Provenance and readiness limits

Every sample is computed from original oscillator/noise synthesis in Scripts/core.py using SHA-256-derived deterministic seeds. No installer, keygen, proprietary sample collection, acoustic recording, or downloaded audio was accessed. Musical rhythm names and selected conventional bol scaffolds describe public musical concepts; newly generated fills and variations are original arrangements.

All WAVs must be described as synthesized approximations. This library is not affiliated with Pitch Innovations, Logic Pro, Sonic Atlas or their owners. The included license grants royalty-free use of the supplied original material; it does not grant rights to vendor software or trademarks.

Linux automated tests establish file integrity and tested generation behavior. They do not establish authentic acoustic timbre, perceptual quality, suitability for a final mix, macOS execution, or host compatibility. Please audition before production use. Expert percussion review is still needed for culturally and regionally nuanced performances.
