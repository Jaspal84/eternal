# Sonic Atlas import status

**Custom sample import has not been verified.** No proprietary Sonic Atlas preset or installation package is included.

Official source attempted on 2026-10-20: https://www.pitchinnovations.com/ — request failed with proxy `Tunnel connection failed: 403 Forbidden`. No current manual, format specification or custom import documentation was retrieved. Accordingly, supported bit depths/formats, import methods, custom multisample mapping, user preset saving and restrictions on third-party libraries all remain unknown. Plain WAV compatibility must not be inferred solely because Sonic Atlas is a sample-based instrument.

The delivery fallback is organized mono/stereo PCM24 48 kHz WAV files in folders 01–08 and 10. Nothing needs to be copied into vendor-managed factory data directories. Refer to your installed version's official manual or vendor support before importing. If it documents user sample import, use that specific command and audition a single WAV first. If not, use these files in Logic Pro Sampler/Quick Sampler, audio tracks or an SFZ-compatible instrument instead.

Questions for the vendor: Can my exact Sonic Atlas version import user WAVs? Does it accept PCM24 at 48 kHz? Can it assign multiple velocity layers and round robins to MIDI notes? Can user presets be saved and distributed, and under what restrictions? Which documented procedure preserves factory content?

The SFZ maps here target compatible SFZ samplers; they are not claimed to be Sonic Atlas presets.
