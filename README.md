# eternal

INDIAN RHYTHMS PRO is an original synthesized Bollywood & Punjabi percussion library for macOS/Logic Pro and other sample workflows. It contains synthetic approximations, not acoustic recordings or proprietary vendor samples.

Source, documentation, tests, SFZ maps and recorded Linux validation results live in [INDIAN_RHYTHMS_PRO](INDIAN_RHYTHMS_PRO/README.md). WAVs, generated MIDI and the multi-GB distribution ZIP are excluded from Git. The source archive GitHub generates is **not** the complete sample library.

The prepared distribution includes 246 mono one-shots, 1,008 MIDI grooves and 1,008 stereo loops, PCM24/48 kHz. See [release and reconstruction instructions](INDIAN_RHYTHMS_PRO/Documentation/RELEASE.md) for downloading a published release or publishing the prepared assets. Publication status must be checked on GitHub; local preparation is not publication.

Six unit tests and 69,467 full-library validation checks passed in the original Linux build. macOS and host playback remain unverified; Sonic Atlas custom import is unconfirmed. The CI workflow runs source tests on Linux and macOS when GitHub Actions is available.
